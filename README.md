# Oumar Dia — Portfolio

> Développeur d'Applications | IA Générative

Bienvenue sur le dépôt officiel du portfolio professionnel d'**Oumar Dia**. Ce site vitrine moderne et performant présente mon profil, mes compétences en ingénierie logicielle et intelligence artificielle, mes réalisations applicatives ainsi que mon parcours de formation.

---

## 📌 Présentation

Ce portfolio est conçu pour offrir une expérience utilisateur fluide, rapide et visuellement captivante. Il met en valeur ma double compétence en **développement d'applications** (Web, Mobile, Architectures logicielle) et en **IA générative** (Architectures RAG, Modèles LLM, Agents autonomes).

---

## ✨ Fonctionnalités

- **Navigation interactive** : Défilement fluide (`smooth scroll`) avec suivi actif de la section visible.
- **Section Hero immersive** : Effets de parallaxe, visuel portrait intégré et particules lumineuses dynamiques.
- **Stack technologique structuré** : Présentation par catégories (Frontend, Backend, IA & Innovation, Mobile, Outils).
- **Parcours & Formations** : Timeline chronologique détaillée de la formation académique au perfectionnement IA.
- **Vitrine de projets** : Mise en valeur du projet phare *CivicAI CI* et des applications métiers.
- **Accréditations & Certifications** : Section dédiée aux certifications Anthropic & Developers.Institute.
- **Formulaire de contact** : Interface de messagerie directe et liens vers les réseaux sociaux professionnels.
- **Design 100% Responsive** : Adaptation sur mobile, tablette, laptop et grands écrans.

---

## 🛠️ Stack Technique

- **Core** : [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite 8](https://vitejs.dev/)
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Icons** : [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Installation

```bash
# 1. Cloner le repository
git clone https://github.com/votre-username/dev-oumar-dia.git

# 2. Naviguer dans le dossier
cd dev-oumar-dia

# 3. Installer les dépendances
npm install
```

---

## 💻 Développement Local

```bash
npm run dev
```

L'application est disponible localement sur `http://localhost:5173`.

---

## 📦 Build Production

```bash
# Générer le bundle de production
npm run build

# Prévisualiser le build localement
npm run preview
```
